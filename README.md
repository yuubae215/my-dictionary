## 変換の進め方

原辞書の部（第I部〜第V部＝RAMI 4.0 Layers 軸、および6章＝メタ語彙）を単位として、1部ずつ ISO 704 形式へ写像する。写像作業（定義文の逐語読み直し）はそれ自体が概念ドリフト検出器として機能するため、各部の変換時に次をセットで行う。

1. 定義文と命名意図のズレ審査。**英語主名称・和文名・別称は別々に**定義文と突き合わせる（3要素が同時にズレるとは限らない）
2. 部立て説明文など、前文の件数・範囲の整合性チェック
3. 関連エントリへの関係型（is-a / part-of / refers-to / constrained-by / transforms / calibrated-from / aligns-with）付与。`mates-to` は全6編で確定使用ゼロのため廃止（`decisions.md` D-2026-09-02-05）
4. **本文（定義文・用法上の注意）が名指しする他エントリが、関連エントリ欄に載っているかの機械照合**、および**対比ペアの上位概念が辞書内にエントリとして立っているかの確認**
5. **その編を参照している先行編の forward reference の解決**（各編は変換時点の状態で書かれるため、後続編が成立しても遡って更新されない）
6. 見つかった判断はすべて `decisions.md` に記録してから次の部へ進む
7. そのうち先送りしたもの・原辞書への推奨は、同じコミットで `backlog.md` にも登録する

**原辞書5章（対象語彙45概念・現場語85語）と6章（メタ語彙14概念）の変換は完了。** 概念ドリフトの検出は59件中3件（第I部1.07、第IV部4.01、メタ語彙M.11）で検出率5.1%。うち1.07は概念分離、4.01とM.11は名称是正で処置した（4.01は名称が定義文より狭く、M.11は広いという逆向きのズレ）。

第M編の変換にあわせて、先行編に残っていた forward reference（メタ語彙への13箇所、既変換編への38箇所）をすべて解決し、`mates-to` 関係型を廃止した（全6編・59概念で確定使用ゼロ）。編をまたぐ概念参照の記法は `第N編3.M` に統一した（旧記法は原辞書の採番と衝突する。`decisions.md` D-2026-09-02-13）。

**対比ペア6組の上位概念を新設した**（`eed:0146`〜`0151`、いずれも新設提案）。子概念だけが並んでいると、読み手はそれが何の一種なのかを掴めないまま定義文に入ることになるためである。親概念はそれぞれの子の直前に置いたため、第2・3・4・M編の採番が繰り下がった（恒久IDは不変。`decisions.md` D-2026-09-02-12）。本仕様書のエントリ数は原辞書59＋新設提案7＝66件になった。

未決事項は `backlog.md` に集約している（判断待ち1件・提案値の確定待ち5件・原辞書へのフィードバック15件）。第M編の変換で判断待ち5件（B-02〜B-05・B-07）を消化したため、**残る判断待ちは B-08（`calibrated-from`・`aligns-with` の正式採用可否）のみ**であり、その前提も次の作業単位である全編化附属書の作成と同時に満たされる。

エントリを書き加える側が必要とする「新設・分割・統合の判断基準（ISO 704準拠の3段階判定）」は `decisions.md` 冒頭にある（原辞書6.3節がそこを案内している）。
