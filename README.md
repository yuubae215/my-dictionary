## 変換の進め方

原辞書の部（第I部〜第V部＝RAMI 4.0 Layers 軸、および6章＝メタ語彙）を単位として、1部ずつ ISO 704 形式へ写像する。写像作業（定義文の逐語読み直し）はそれ自体が概念ドリフト検出器として機能するため、各部の変換時に次をセットで行う。

1. 定義文と命名意図のズレ審査。**英語主名称・和文名・別称は別々に**定義文と突き合わせる（3要素が同時にズレるとは限らない）
2. 部立て説明文など、前文の件数・範囲の整合性チェック
3. 関連エントリへの関係型（**is-a / part-of / refers-to / constrained-by / transforms** の5型）付与。`mates-to` は全6編で確定使用ゼロのため廃止（`decisions.md` D-2026-09-02-05）、`calibrated-from`・`aligns-with` は候補箇所が概念のすべての個体について成立しないため不採用（D-2026-09-03-02）
4. **本文（定義文・用法上の注意）が名指しする他エントリが、関連エントリ欄に載っているかの機械照合**、および**対比ペアの上位概念が辞書内にエントリとして立っているかの確認**
5. **その編を参照している先行編の forward reference の解決**（各編は変換時点の状態で書かれるため、後続編が成立しても遡って更新されない）
6. 見つかった判断はすべて `decisions.md` に記録してから次の部へ進む
7. そのうち先送りしたもの・原辞書への推奨は、同じコミットで `backlog.md` にも登録する

**編を足し終えたら、全編を1つの母数として数え直す。** 部ごとの変換が**概念ドリフト**（名前と定義文のズレ）を拾うのに対し、全編化は**集計ドリフト**（エントリの増減が集計の記述に反映されない）を拾う。後者は「`Instance` は全件がInformation層」のように自分の編の外側についての主張を含むため、1編を変換しているかぎり検証できない（`decisions.md` D-2026-09-03-05）。
