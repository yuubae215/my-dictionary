# review/dogfooding/

dogfooding の実施記録を置く。手順は `review/2026-10-04-dogfooding-procedure.md`、記録の書式は同 §6 による。

| ファイル | 内容 |
| :--- | :--- |
| `extract.py` | 手順 §4.2 の機械的な抽出。対象文書のテキストから空間語の出現を1出現1行で拾い、記録ファイルの出現一覧の形で出力する |
| `YYYY-MM-DD-<文書の種類>.md` | 1文書につき1ファイルの実施記録。1本目は `2026-10-04-data-exchange-convention.md`（ROS REP 105） |

## 抽出スクリプト

```sh
python3 review/dogfooding/extract.py <対象文書.txt> > /tmp/occurrences.md
```

- 検索語は `pilot/part0-annexes.md` の附属書A（現場語と同義・異表記）、G.1（和文名）、G.2（主名称）を実行時に読む。辞書を改訂すると検索語も追従する。手順 §4.2 の目視用方向語だけはスクリプトに書き写している。
- 1行の中では長い語を優先する。「搬送安定姿勢」を「姿勢」としても数えることはしない。
- 1文字の方向語（上、下、前、後、表、裏、正、逆）は「以上」「下記」も拾うため、出典欄を「方向?」とする。目視で空間の用法かを判断し、違えば行を消す。`--no-single` で出力から外せる。
- 抜粋は前後8文字（`--context` で変更）。手順 §2 のとおり、対象文書の原文はリポジトリに置かない。対象文書のテキスト自体もリポジトリの外に置く。
- 機械抽出は §4.2 の半分である。辞書に未登録の空間語（M6 の候補）はこのスクリプトでは拾えないため、目視での抽出を必ず併用する。

## 2人で実施する場合の進め方

1本目は Claude（辞書の書き手側）とリポジトリの持ち主（書き手以外の役）の2人で実施する。
手順 §4.1-3 のとおり、§4.2〜§4.5 は互いの結果を見ずに独立に行う。

1. 抽出（§4.2）は共有してよい。出現一覧の「#」「箇所」「語」を両者で同じものにしておくと、§4.7 の突き合わせを出現番号で行える。
2. 主語、参照枠、代表形、区分（§4.3〜§4.5）と、M6 の3段判定（§4.6）は各自が別々に埋める。先に埋めた側は、相手が確定させるまで自分の結果をコミットしない。代わりに結果ファイルの SHA-256 を記録ファイルに書いて封をし、後から書き換えていないことを示せるようにする。
   持ち主の入力は Artifact の判定シートで行い、Claude はシートの共有データベースから読む。
3. 両者が確定させたら、記録ファイルに両者の列を並べて §4.7 の一致率を出す。
